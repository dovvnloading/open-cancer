## Primary proportionality restriction and all comparisons

For two age groups y (younger) and o (older), define Q(y,o) = (lambda_P,o/lambda_P,y)/(lambda_N,o/lambda_N,y). Equal proportional age effects across the two receptor classes require **Q=1 for every age pair**. At a single age the population exposure is shared between receptor classes, so Q=(P_o/N_o)/(P_y/N_y); exposure cancels. This is a receptor composition odds ratio among cases, equivalent to a ratio of age-specific incidence rate ratios under common within-age denominators. It is NOT the fraction of all cancer cases that are receptor-positive, a causal rate effect, or a hazard estimate.

Freeze **all 10 ordered younger→older pairs** of the five age bins, 4 adjacent and 6 nonadjacent, as one family. Display every pair, not only visually striking declines. The 70–74→75–79 and 75–79→80–84 edges are of contextual interest from #80, but have **no** separate test alpha. Full-proportionality failure is observable if the *95% simultaneous, missing-status-enveloped interval* for **any** one Q excludes 1 on either side; equality at 1 does not fail. Do not select direction after seeing outcomes. Both ratios and signed receptor-specific rate changes may be reported, with no mechanism attributed.

## Primary unknown allocation, extreme bounds, sampling rule

For each age independently, form T=P+N+M. The **primary proportional allocation** is k = floor(M*P/(P+N)+0.5), i.e. nearest integer of the number assigned positive, with exact halves assigned positive; completed counts P*=P+k, N*=N+M−k. Preserve integer counts and disclose k per age. This is a *scenario*, not verified missing-at-random. Fixed sensitivities at each age: **all-to-positive** k=M; **all-to-negative** k=0. For each pair also show both **mixed corners**: younger k=M/older k=0 and younger k=0/older k=M. These 4 corner tables span the sharp allowed Q point-estimate range because odds(P*/N*) increases in k. Do not pretend mutually inconsistent corner allocations all hold simultaneously.

Conditionally assume 2016 registry age/class counts are independent Poisson marks with fixed age exposures. On completing an allocation at age a, conditional on T_a the number of P* events follows a binomial(T_a, p_a). The assumption is a *process-model* approximation for registry enumerations, ignores exposure/coding/selection error and treats the hypothetical completed labels as true, not a calibrated model for unknownness. Compute exact equal-tailed Clopper–Pearson intervals for p_a, inverting regularized beta tails in stdlib Python; all count totals are positive. For **simultaneous at-least-95% coverage of five age proportions**, use Bonferroni: individual error 0.05/5=0.01, split 0.005 each tail. Every pairwise age odds ratio is a monotone transform of these 5 intervals, so the entire 10-pair family is multiplicity-aware without treating pairs as independent. Use unrounded floating-point values for decisions, expose numerical precision/tolerance, and document that hypothetical allocation conditional coverage does not model classification missingness.

For each named allocation scenario, interval for Q is [odds(L_o)/odds(U_y), odds(U_o)/odds(L_y)] using the agewise CP limits. The **uniform unknown-allocation envelope** has lower endpoint using **older all-negative CP lower** and **younger all-positive CP upper**, and upper endpoint using **older all-positive CP upper** and **younger all-negative CP lower**. This projection covers *every integer assignment* of the pooled unknown cases in each age and is the primary failure interval. Explicitly report the five scenario intervals for each pair and the envelope. Check monotonicity/inclusion mathematically and in tests; do not rely on exact float equality from an optimiser. Intervals are conservative and possibly very wide. They are sampling intervals *conditional on the marked-Poisson model*, and missingness sensitivity bounds, not uncertainty from all epidemiologic causes.

## Rounding sensitivities and verdict categories

Count-derived Q is invariant to published rate rounding. Independently audit rounded Table 1 one-decimal positive/negative rates: for every pair, compute worst-case Q under each printed rate's closed ±0.05 interval and, as an intentionally wider sensitivity, under ±0.10. Each Q range is [P_o_low*N_y_low/(N_o_high*P_y_high), P_o_high*N_y_high/(N_o_low*P_y_low)]. Keep values positive; this is **rounding-only**, not a sampling CI, cannot replace the count-based rule. Display every pair's printed-rate Q and both ranges, preserving any discrepancy with count Q.

Apply categories in order:
1. **UNTESTABLE** if required aggregate cells/denominators fail validity, unresolved partition is negative, binomial inversion cannot be certified, or there is no status panel. HER2 is always *separately untestable* here.
2. **FALSIFIED** if any pair's complete unknown-allocation/simultaneous interval is wholly above 1 or wholly below 1.
3. **CONSISTENT** if none falsifies and **all five scenario intervals for every pair contain 1**.
4. **INCONCLUSIVE** otherwise (some allocation-dependent intervals exclude 1 but none passes the adversarial all-allocation rule).

CONSISTENT means compatible under the stated measurement/model assumptions, **not** equality proved. INCONCLUSIVE is neither a null acceptance nor biological support. The category order, thresholds, data and model cannot change after numerical results.

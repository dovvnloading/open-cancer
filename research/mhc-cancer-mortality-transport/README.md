# Does MHC-I family size improve cancer-mortality transport across mammalian orders?

**Nonclinical, unreviewed computational research. No medical or veterinary advice.**

This directory tests whether MHC-I gene-family size adds predictive information
to body mass, adult life expectancy, and diet when an entire mammalian order
is absent from training. **The frozen verdict is untestable: inconclusive on
the available panel.** The small order-balanced improvement has an uncertainty
interval crossing zero, and the death-weighted contrast is
negative. The result is conditional on the specified models,
source population, scoring target, and uncertainty procedure. It is not a
functional immune-repertoire measurement or an estimate of immune causation.

## What was tested

Both regressions receive exactly the same species and the same baseline:
natural-log body mass, natural-log adult life expectancy, and the source's
binary mammal-prey indicator. The extended rule adds only natural-log
`MHC-I family size + 1`. Continuous predictors are standardized using training
species only. The ridge penalty is fixed by the protocol. Neither a fitted
MHC slope nor an in-sample association decides the verdict.

Each held-out order is absent from both model fits. The primary loss averages
species within an order and then averages orders equally. It asks how well
the rule transports to an equally weighted *observed order*, rather than
letting species-rich orders or large mortality denominators silently define
the target. The death-weighted result is reported separately.

Recorded zero-case species contribute the probability penalty for predicting
cancer deaths when none were observed. The primary panel includes the naked
mole-rat and Patagonian mara. Their removal and removal of zero cases occur
only in labelled sensitivities. Excluding zeros is outcome selection; its
result cannot rescue the primary claim.

Uncertainty deletes a whole order and repeats the entire order-holdout
pipeline, including training transformations and refitting. It therefore
captures training-composition instability as well as changes in the test
orders. The order jackknife still assumes more exchangeability than a
selected, deeply related set of mammalian orders can guarantee. It does not
quantify all sampling, diagnostic, or phylogenetic uncertainty.

The pinned tree supplies fair-proportion evolutionary-distinctiveness
weights and a deterministic deeper-block stress. These are explicitly
labelled sensitivities. Fair-proportion reweighting does not fit correlated
phylogenetic residuals. The deeper cut is outcome-blind and keeps orders
intact; its limited block count is reported without moving the cutoff.
Neither sensitivity is a phylogenetic logistic mixed model, and the analysis
does not establish residual phylogenetic independence.

## Source, counts, and reuse boundaries

The source is Vincze et al., *Immunological surveillance against cancer across
mammals*, Nature Communications (2025),
[DOI](https://doi.org/10.1038/s41467-025-65286-x),
[article and Methods](https://pmc.ncbi.nlm.nih.gov/articles/PMC12644480/).
The paper-linked repository is pinned at
[`2c8a5c5`](https://github.com/OrsolyaVincze/VinczeEtalNatComm_MHC-cancer/tree/2c8a5c5b5fda6fb34c86b0e5a2b6a58dcc85cc3e).
Only `SourceData_FINAL.csv` and `phylogeny.tre` supply the new analysis inputs.

The repository licence audit was performed before reading the data. No
LICENSE or README was present at that commit, and GitHub's licence metadata
was null. The article specifies
[CC BY-NC-ND 4.0](https://creativecommons.org/licenses/by-nc-nd/4.0/).
We do not infer blanket redistribution or adaptation rights, nor assume that
the article licence necessarily licences every GitHub asset. This directory
contains original code, source identifiers and hashes, and narrow transformed
numerical species summaries under the requested aggregate-only fallback.
It mirrors no upstream CSV, tree, R program, article prose, or individual
Species360 record. The project MIT licence does not relicense upstream
material; the fallback and passed tests are not legal clearance.

Source text was read through GitHub's API. No browser file download was used,
no download prompt was accepted, and no restricted records were requested.
The optional fetch script reads the pinned raw text in memory and checks
both Git object identities and newline-normalized SHA-256 values before
deriving the small tables. It does not save raw source assets.

CMR uses deaths with known cause as its denominator. Nominal integer cancer
deaths are reconstructed only after a decimal-resolution audit. The short
decimals with nonunique numerators remain explicitly ambiguous, and every
compatible assignment is evaluated. ICM is a survival-model cumulative
mortality estimate: **ICM times RDI is never treated as a recovered count**.
Missing CMR stays missing even when ICM is zero. Adult lifespan here means
post-maturity adult life expectancy, not maximum lifespan.

The source article's Methods population summary differs from the pinned CSV's
available rows. This analysis uses the frozen, file-derived panel and records
the discrepancy; it does not claim to recreate the authors' published panel.
The upstream R program also names a different input CSV. This directory uses
an original reader of the explicitly pinned file and does not copy the R code.

## Falsification, novelty, and remaining uncertainty

The reported falsification attempts preserve adverse results: all
rounding-compatible count assignments, removal of the named rodents,
outcome-selected zero removal, equal-species training weights, weaker and
stronger fixed ridge penalties, phylogenetic weighting, deeper-clade
holdouts, and deletion of each order. None was chosen after observing its
score. The negative and inconclusive verdicts were specified before fitting.

The MHC-family-size association is **published prior work**. The new question
is incremental out-of-order predictive transport after the combined baseline,
with inclusive zeros, declared exceptions, and order-level uncertainty.
This is a bounded methodological contribution within this repository, not a
new immune mechanism, proof that Peto's paradox is resolved, or a claim of
being first in the literature. A targeted literature check found the source
association and related comparative-genomics work; it was not an exhaustive
priority search. The targeted queries were `MHC cancer mammals out-of-sample
gene family` and the source title with `prediction` (accessed 2026-11-18).
The related primary study checked was
[*The molecular evolution of cancer associated genes in mammals*](https://doi.org/10.1038/s41598-024-62425-0);
it is context for comparative genomic associations, not evidence that this
specific transport test was absent from all prior work.

[PR #75](https://github.com/dovvnloading/open-cancer/pull/75) found that its
inverse-lifespan mutation scaling leaves a target-cell factor unresolved.
That motivates examining an additional observable; it does not identify MHC
as that missing causal factor. Mortality comes from the same Species360/ZIMS
provenance family used by that earlier work. A later extraction does not prove
nonoverlapping animals: **this is not independent mortality validation**.

The immune line of
[PR #59](https://github.com/dovvnloading/open-cancer/pull/59),
[PR #67](https://github.com/dovvnloading/open-cancer/pull/67),
[PR #72](https://github.com/dovvnloading/open-cancer/pull/72), and
[PR #76](https://github.com/dovvnloading/open-cancer/pull/76) distinguishes
functional antigen loads, empirical proxies, and transport. This gene-family
count does not observe those functional repertoires, peptide quality,
expression, immune killing, or complete presentation loss. Even a stable
predictive gain would not identify immune causation. A failure to establish
a gain would not disprove immune surveillance.

Further limitations include selected managed populations, aggregation across
cancer sites and ages, known-cause ascertainment, an adult-lifespan covariate
estimated from related mortality information, variable genome annotation,
and no new population or temporal validation cohort. Taxonomic order is a
stressful holdout unit, but it is not an independent sample of all mammals.
The explicit verdict is about the frozen prediction rules and available
observations only.

### Hostile self-review record

Before freezing, a separate review corrected the wording on held-out count
recovery and required sensitivity-fit failures. Source review rejected the
assumptions that a public repository grants redistribution rights, that ICM
can supply a count, that a short decimal proves an exact numerator, or that
a two-block tree split establishes broad phylogenetic transport. These
findings shaped the frozen data and decision rules.

After fitting, an independent code and source review recalculated the primary
species losses, order and death-weighted scores, and jackknife uncertainty;
synthetic examples checked the different training weights. The review found
no substantive numerical or leakage defect. It hardened the positive-verdict
helper against incomplete or unconverged count grids and clarified that full
stored prediction and coefficient records concern the primary analysis.
The offline test additionally caught a display-order difference between fresh
and JSON-loaded result objects; canonical gate ordering fixed it. These are
implementation corrections, not changes to the frozen analysis.

The most consequential adverse checks remain visible: the apparent gain
depends strongly on a singleton order, removing Primates reverses it, the
death-weighted contrast is negative, and the uncertainty interval crosses
zero. Favourable point estimates in the declared sensitivities cannot repair
that failed uncertainty gate. The appropriate downgrade is an inconclusive
directional claim, not either established transport or established absence.

The offline test recomputes the complete report and independently audits
counts, fitted optima, scores, uncertainty, held-out-label isolation, tree
operations, and normalized hashes. No protocol deviation or post-fit change
to the frozen panel, score, penalty choices, uncertainty, or decision rules
was made. No biological claim is upgraded on the basis of AI agreement,
content hashes, or green CI. Remaining uncertainty is retained as uncertainty.

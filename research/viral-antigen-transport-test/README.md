# Does the Merkel viral-antigen offset transport to other cancers?

**Nonclinical, unreviewed computational research. No treatment, diagnosis,
surveillance or patient-selection advice.** This is an aggregate-only,
noncommercial methodological audit. Tests, hashes and AI critique do not
establish source truth, biological causation, external scientific review or
clinical validity.

## Verdict

**Viral offset fails to transport under the frozen numerical rule.** The
selected KEYNOTE-040 HPV-positive stratum has a published response interval
entirely below the unchanged offset model's minimum possible prediction.
The gap survives the prespecified source-rounding allowance and all inherited
point-offset scale scenarios. It is a range contradiction for every
nonnegative TMB under those fixed offsets; no TMB value is invented.

**Comparative improvement over TMB alone remains untestable.** The accessible,
reusable aggregates do not identify a complete eligible positive/negative
response-and-TMB pair. The range failure supplies no paired MSE comparison.
The baseline's possible response range remains compatible with the
KEYNOTE-040 interval, which is a necessary condition rather than a successful
baseline prediction.

**Strict historical-independence sensitivity: untestable.** The inherited
fit contains a head-and-neck parent whose trial composition is unresolved.
KEYNOTE-040 is conservatively flagged as possibly overlapping. Matching a
rounded whole-trial percentage cannot establish overlap or independence.
The declared-rule failure therefore is not established as an independent
out-of-sample failure. This audit also does not establish that missing data
never existed or could not be obtained by another access method.

There is adverse partial evidence. In the eligible EBV-positive camrelizumab
cohort with a printed TMB median, the unchanged Merkel offset increases a
prediction that already exceeds the observed no-response result. Its
single-stratum point error worsens at every inherited scale and training
endpoint scenario. The generated report below shows the calculations.
The small positive-only cohort supplies neither a published ORR interval nor
a negative arm, so it cannot become a prespecified complete-pair failure.
Observed no responses do not imply a zero population response probability.

The other eligible HPV response intervals remain compatible with the primary
model's possible range. Inherited high-endpoint scenarios produce additional
contradictions, whereas lower-endpoint scenarios can remove the KEYNOTE-040
contradiction. Training-endpoint sensitivities are retained without replacing
the primary point offset or being called transported confidence intervals.
A selected HCC subgroup supplies a secondary offset-floor contradiction;
its hepatitis-etiology classification, selected population and different
assessment method keep it outside the required HPV/EBV verdict. That
counterevidence is retained without changing the frozen scope.

The fixed numerical transport claim fails its prespecified range criterion;
the independent comparative claim remains unanswered. A non-mutational
antigen contribution remains a biological hypothesis that these marginal
data do not identify. Neither result is a calibrated statistical rejection
of viral immunogenicity or a clinical conclusion.

## What this teaches about a non-mutational antigen term

[PR59](../immune-escape-neoantigen-clonality/) concerns functional presented
antigens per cell under specified branching, killing and escape assumptions.
Its homogeneous large-load shape does not establish that median TMB measures
functional exposure or that RECIST response equals eradication.
[PR67](../immune-escape-pancancer-test/) failed its declared predictive
improvement criterion over the simpler TMB comparator.
[PR72](../merkel-viral-antigen-test/) found a conditional point improvement
within the Merkel programme, limited by its complete interval rule.

A conceptual total antigen load can include mutation-derived and
non-mutational targets. But a universal response-equivalent offset also
assumes comparable quality, expression, presentation, coverage, immune
context, effective founder burden, ceiling and endpoint mapping. HPV, EBV
and hepatitis labels measure none of those jointly. The per-Mb assays also
count different variant classes. A common scale is a scenario, not a
calibrated measurement bridge.

The unchanged offset imposes a positive response floor. KEYNOTE-040 violates
that numerical constraint under the primary scenario, including source
rounding, so missing TMB cannot rescue this specific fixed-offset prediction.
This is not evidence that viral antigens are absent or never contribute:
antigen presentation, assay/status classification, effective magnitude,
response mapping and tumour context can all break the universal-offset
assumptions. Historical independence is unresolved, and the inherited lower
calibration scenarios show parameter sensitivity.

The eligible EBV partial point calculation is also adverse. Missing
covariates do not justify borrowing a median from another population.
Even complete plug-in scoring would remain
ecological: response at a median generally differs from mean response under
a nonlinear curve. The population-median stress test uses the correct
offset-dependent lower endpoint, but cannot create a missing empirical
response interval or identify an actual TMB distribution.

### Honest novelty assessment

Viral immunogenicity, viral-status response associations and low-mutation
viral tumours are established motivations, not repository discoveries.
The efficacy trials already evaluated viral status.
[Hanna](https://doi.org/10.1172/jci.insight.98811),
[Haddad](https://doi.org/10.1136/jitc-2021-003026),
[Pfister](https://doi.org/10.1002/cam4.5434),
[Valero](https://doi.org/10.1172/JCI169823) and the gastric studies examine
response alongside genomic/viral biomarkers. The later
[durvalumab biomarker analysis](https://doi.org/10.1158/1078-0432.CCR-22-2765)
also cautions against assuming that viral status always separates measured
TMB in treated cohorts. Their fitted models and endpoints differ from this
pre-fixed offset.

The defensible contribution is this repository's publicly frozen cross-virus
**transport attempt**, with exact inherited scenarios, source/missingness
audit, a prespecified numerical range failure and explicit abstention on
independent paired improvement. It is not completed
independent validation, a new biological mechanism, a validated biomarker or
a priority claim. Broader searching could reveal an equivalent numerical
exercise. CI success would not change that assessment.

## Reproduce and review

From the repository root:

```bash
python -B research/viral-antigen-transport-test/analysis.py --check
python -B research/viral-antigen-transport-test/analysis.py --json
python -B -m unittest discover -s tests -p 'test_research_viral_antigen_transport_test.py' -v
```

`--write-report` updates only the marked results block. It never changes
the protocol, inherited data or transcriptions. The dedicated test is
offline, standard-library-only and below a minute. Decimal reference
calculations independently check predictions and errors. Synthetic
mathematical fixtures exercise empirically unavailable cases; they are
labelled and never presented as observations.

The [test](../../tests/test_research_viral_antigen_transport_test.py) checks
the immutable protocol/source hashes, all generated numbers, count consistency
and documented exceptions, primary-family duplication, TMB eligibility,
target-independent constants, negative controls, uncertainty and verdict
priority. Hashing normalizes CRLF/CR to LF; every file key is constructed
with `Path.as_posix()` and sorted canonically. Required provenance fields
cannot certify that a source claim is true; that remains a manual audit.

Existing repository gates:

```bash
python -B scripts/validate.py
python -B -m unittest discover -s tests -v
node --test tests/*.test.*
```

The existing PR workflow discovers the new test without a workflow change.
This work remains nonclinical and unreviewed regardless of software results.

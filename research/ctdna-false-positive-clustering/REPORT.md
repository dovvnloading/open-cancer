## Hostile self-review and attempted falsification

1. **Did we confuse serial-negative with nonrecurrent?** No: 10/126 serial-negative recurrence is carried into the 2×2 table, explicitly separated from 10/64 positive nonrecurrence. Both groups of 126 are separately reconstructed and regression-tested.
2. **Does the article's use of “specificity” prove sample denominator identity?** No: it suggests a standard interpretation but never supplies a 637-sample-to-126-person bridge. To label 18 samples as false-positive calls among the same people would smuggle in the missing joint relation.
3. **Could 637 simply be a subset with different QC/time eligibility?** The published Methods allow QC/extraction exclusions and treatment-specific surveillance start dates; without a crosswalk, this contrary interpretation is not excluded. We do *not* claim the cohorts are provably different—only that the equality needed by the test is not established.
4. **Is the 1–8 bound demonstrably valid in the nonrecurrent subset?** It is printed for all 190 participants; per-person eligible G2 counts are not printed. Assigning the full-cohort bound to a differently defined subset would be another assumption.
5. **Does the patient-level numerical identity itself settle clustering?** No. The exact 116/126 fraction and subtraction 637–619 are unrelated marginal statements without a shared sample-to-person map. A collision count, iid conditional tail and effect size are withheld.
6. **Was the prior literature ignored?** No. A 2024 tissue-free epigenomic study describes six transiently positive patients, a 2023 case report demonstrates a condition-associated methylation positive, ESMO covers clonal haematopoiesis, and alpha-CORRECT explicitly defines surveillance specificity and follow-up. None supplies this GALAXY denominator bridge or quantifies a within-person clustering parameter for this precise cohort. No first-discovery claim is made.
7. **Can a failed software test be mistaken for clinical validation?** No. Fail-closed tests exercise missing data, duplicate counts, contradictory counts, status tampering, exact fractions and line-ending/POSIX path invariants. Passing tests verify a deterministic audit only. The full repository CI is separately reported on the PR.
8. **Is the licence an assumption inherited from the queue?** No. Official PMC article HTML copyright-and-licence explicitly says CC BY 4.0; Nature marks the publication open access. Only sparsely selected attributed numerical facts have been retained.
9. **Could re-analysis identify an etiology anyway?** No. Even a future robust occupancy rejection could not discriminate clonal haematopoiesis, patient-specific background, methylation cross-reactivity, true subclinical disease that cleared, batch effects, contamination or endpoint ascertainment. No clinical advice is made.
10. **Was the freeze genuinely prior to code/results?** The GitHub protocol-only branch commit 0d39a703653540cbd9402f84327dfecdb3c41c10 precedes the remaining material. Counts were visible before freeze, so it is deliberately not characterized as blinded preregistration. The branch parent was main 307aa3c336548046c344772f3bedd4f325a1b1a0. No conditional occupancy computation was run.

## Reproducibility record and limits

The offline analysis script fails closed at G2–G4, checks exact patient table and both printed fractions with `Fraction`, and emits stable JSON including normalized SHA-256 checksums (CRLF/CR to LF; `Path.as_posix()` keys). Dedicated unittest coverage: 8 local tests passed on Python 3.13.5 in under a second, including Windows-style path and line-ending fixtures; physical Windows and local Python 3.12/3.14 runtimes were not available. No floating point estimators are computed. The environment could not resolve github.com for a shell `git clone`; authenticated GitHub connector operations were used to preserve the remote main parent and protocol chronology. This is a limitation of the local reproduction transport, not an article-download issue.

**Required new evidence for a future variant:** an authoritative crosswalk specifying that the 637 denominator samples are precisely the eligible surveillance tests from the same 126 nonrecurrent patients, with compatible sample-level calls, QC, and each person's 1–8 eligible test count (or defensible hard bounds). Without it, no population-level or within-person correlation parameter is identified from these marginals.

# Do BRAF V600E colorectal organoids depend more often on EGFR?

**Nonclinical, unreviewed computational research. No treatment advice.**

In a single prespecified analysis of Sanger colorectal organoids without a reported RAS driver mutation, EGFR knockout met the authors' essentiality threshold in **6/8 BRAF V600E donors (75%)** and **31/35 reference donors (89%)**. The difference was **−13.6 percentage points** (95% interval **−48.3 to +9.4**, two-sided Fisher **p = 0.308**). The frozen verdict is **inconclusive**. The observed direction runs against the prediction of greater basal EGFR dependence in V600E organoids. Only eight mutant donors contributed, and EGFR was already essential in most reference models.

The [protocol](PROTOCOL.md) was committed locally at `7667f44e52f39192802f2b9940a01b868363f5a4` before computing outcomes. GitHub assigned a different commit ID at publication. The parent and protocol-only tree (`f223fce0419df4982e394360aed5c7b61a8b069d`) match the local freeze. [Published protocol commit](https://github.com/dovvnloading/open-cancer/commit/2e38e0ed49b0f10bec65281babc9fb4a13015116) #98 analyzed fold changes. This test uses the distinct binary matrix built from BAGEL2, where 1 indicates a gene met the organoid-specific 5% FDR essentiality threshold. The underlying screens overlap. This is one new genotype–gene contrast using an alternative score, with no independent cohort replication.

The paper describes 85 colorectal models. Cell Model Passports classifies one as a colorectal adenoma, outside the frozen carcinoma criterion. The reference group had WGS evidence and no BRAF variant in the Sanger mutation summary. That summary contains selected variants and provides no per-locus coverage guarantee. RAS copy-number events, other pathway alterations and MSI could still differ between groups. The [aggregate output](derived/egfr.json) contains the counts, source hashes and statistical result.

## Hostile review

* **Was #98's “general compression” established?** Its rule defaults to that label when WRN's interval fails to separate from every comparator. Overlapping intervals cannot establish a universal compression factor. CTNNB1 had three positive models per platform and an unstable denominator. WRN–MSI is a synthetic-lethal relationship and KRAS-mutant addiction is an oncogene relationship. The WRN (0.46) and KRAS (0.52) ratios describe these two group contrasts on the #98 scale. The new EGFR test does not estimate either ratio.
* **Would this test falsify feedback after BRAF inhibition?** It could contradict the prespecified prediction of *higher basal EGFR essentiality*. Inhibitor-triggered feedback and a BRAF knockout-by-EGF interaction require perturbations absent from this matrix. The binary endpoint also loses information about the strength of dropout above the threshold. Even a clear basal association could not isolate medium as its cause.
* **Could duplicate cultures or a coding error account for the result?** An independent SQL reconstruction of the four inputs verified the two counts, the release denominator and the donor selection. A separate statistical implementation reproduced the Fisher p-value and the Newcombe interval. Only the same frozen contrast was evaluated. These checks establish computational agreement.

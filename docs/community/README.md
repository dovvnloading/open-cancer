# Technical project participation

Open Cancer is a compute-first AI software project; it is not a staffed research institution or a reviewer-recruitment initiative. There is no requirement to find scientists, labs, professors, or volunteers.

For reproducible code bugs, execution failures, source-connector defects, scalability, and tests, use [GitHub Issues](https://github.com/dovvnloading/open-cancer/issues) **only when there is an actionable engineering task with a reproduction and testable acceptance criteria**. The repository exposes a single engineering issue form.

For the runnable coordinator, worker JSON protocol, sharding and checkpoints, use [docs/compute.md](../compute.md). For routine monitoring and periodic reports, see [GitHub Actions](https://github.com/dovvnloading/open-cancer/actions); these must not create new Issues. For project scope and data restrictions, see [README](../../README.md) and [DATA_POLICY](../../DATA_POLICY.md).

Historical independent-review documents are optional archival material, not active requirements for anyone to contribute AI computation.
